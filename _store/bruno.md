It serves as an alternative to Postman and Insomnia, storing API collections directly in a folder on your filesystem using a plain text markup language called Bru. Bruno is offline-only, with no cloud sync, prioritizing data privacy and local-first workflows. It supports REST, GraphQL, and gRPC APIs and is available on Mac, Windows, and Linux.

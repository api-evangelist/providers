description: Synervoz is a Toronto-based software company building for interactive voice and video applications with complex real-time audio requirements. Its flagship product, the Switchboard SDK (branded Switchboard Audio SDK), is a modular, cross-platform audio engine built on a C++ core with higher-level bindings for Swift, Kotlin/Java, JavaScript/TypeScript, and React Native, running on iOS, Android, macOS, Windows, Linux, and Web. Switchboard exposes a hybrid audio graph that connects processing nodes — acoustic echo cancellation, real-time communication, speech-to-text, text-to-speech, voice activity detection, stem separation, DSP and generative-audio nodes — with some nodes on-device and others cloud-integrated. Developers integrate via first-party npm and Swift Package Manager libraries and drive the SDK through a language-agnostic JSON-RPC command/response protocol.

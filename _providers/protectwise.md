description: ProtectWise was a Denver-based cloud-delivered network security company providing Network Detection and Response (NDR) — full-packet capture, retrospective threat hunting, and a 3D visual security operations interface ("The ProtectWise Grid"). It published a REST API at api.protectwise.com (v1) using X-Access-Token authentication (username@@token-uuid) with sensors and observations endpoints for querying threat data and indicators of compromise. Backed by Trinity Ventures, ProtectWise was acquired by Verizon in March 2019 for ~$225M and folded into Verizon Network Detection and Response; the standalone protectwise.com domain and API host are now offline. The company's open-source legacy survives on GitHub, most notably the widely-used troika JavaScript 3D/2D visualization framework.

description: Heyzap was a mobile-game advertising, discovery, and monetization company. It began as a social game-discovery network and pivoted into a mobile ad mediation platform, offering iOS, Android, Unity, Cordova, and Adobe AIR/ANE SDKs that let game developers serve and mediate ads across networks such as AdMob, AppLovin, Vungle, Chartboost, AdColony, and Facebook Audience Network. Heyzap was acquired by Fyber (RNTS Media) in 2016 and its brand was later folded into Digital Turbine. Heyzap never published a public REST API; its developer surface was the mobile ad-mediation SDKs distributed via GitHub (github.com/Heyzap) and package registries. The heyzap.com domain is now parked/for-sale and the developer documentation site no longer resolves; this profile preserves the historical, first-party SDK artifacts that remain publicly available.

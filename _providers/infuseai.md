description: InfuseAI is the company behind Recce, an open-source AI data-review agent for dbt teams. Recce validates how code changes impact data by automatically running schema diffs, data diffs, row counts, profile/value/histogram diffs, and downstream column-level lineage / impact analysis on pull requests, so data teams catch breaking changes before they reach production. It ships as a first-party Python CLI (recce) plus a managed cloud platform (Recce Cloud) that adds an AI agent to explain findings, collaboration on PR reviews, and CI/CD integration. Recce is Apache-2.0 licensed and SOC 2 compliant.

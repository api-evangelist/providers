description: Manta Network is a modular Layer-2 blockchain ecosystem for zero-knowledge (ZK) applications, comprising two complementary networks. Manta Pacific is an EVM-compatible Ethereum Layer-2 rollup built on the Optimism OP Stack that uses Celestia for modular data availability, giving developers low-gas deployment of ZK applications through the standard Ethereum JSON-RPC interface (chain ID 169). Manta Atlantic is a Polkadot parachain (Para ID 2104) focused on on-chain ZK identity and privacy, exposed through Substrate/Polkadot JSON-RPC over WebSocket. Developers build with familiar EVM tooling, deploy against a public Sepolia testnet and faucet, and interact with the network via public RPC endpoints, block explorers, and native bridges. Manta Network is backed by Polychain Capital and other investors.

description: Floobits was a real-time collaborative code editing service — "remote collaboration tools for dev teams, work together, apart." It shipped editor plugins for Sublime Text, Vim, Neovim, Emacs, Atom, and the IntelliJ family of IDEs, plus flootty, a shared-terminal tool for pair terminal sessions. Plugins connected editors to shared Floobits workspaces where multiple developers edited the same files and terminals in real time over a synchronizing backend (built on a diff-match-patch model).

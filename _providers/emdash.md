description: Emdash (YC W26) is a free, open-source agentic development environment (ADE) built by General Action, Inc. in San Francisco. It lets engineering teams run multiple AI coding agents such as Claude Code and Codex in parallel, each isolated in its own git worktree so their work never collides, then compare, review diffs, and open pull requests from one desktop app. Emdash supports 25+ coding agent providers without vendor lock-in, schedules recurring agent work (bug sweeps, release prep, reviews), previews apps in a built-in browser, runs agents on remote machines over SSH, and manages a shared library of reusable prompts, skills, and MCP servers. It is a local-first desktop application (macOS, Windows, Linux) distributed as signed binaries and a Homebrew cask rather than a hosted web API; there is no public REST API surface.

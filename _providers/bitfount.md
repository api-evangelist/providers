description: Bitfount is a full-stack federated AI and data science platform that lets organisations train, fine-tune, evaluate, and run inference on sensitive data without moving it. Instead of centralising data, Bitfount "sends the AI model to the data" — datasets stay behind the owner's firewall on their own infrastructure at all times, protected by built-in privacy-enhancing technologies (differential privacy, private set intersection). Developers work through the open-source Bitfount Python SDK (typed wrappers around the Bitfount REST API on hub.bitfount.com), a no-code desktop app, or a Docker pod image. Typical use cases include federated learning, federated evaluation, clinical trials, biomedical research, trusted research environments, and cross-party data partnerships. Backed by speedinvest.

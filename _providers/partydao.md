description: 'PartyDAO is the decentralized autonomous organization behind Party Protocol, an open, GPL-3.0 protocol for on-chain group coordination that aims to make Ethereum "multiplayer." Party Protocol lets groups form a Party (a shared Ethereum account with members, an inventory, and governance), collectively crowdfund to acquire assets, govern shared holdings, and distribute value to members — all through audited Solidity smart contracts rather than a hosted HTTP API. PartyDAO also ships Party (party.app), a consumer application built on the protocol. The developer surface is entirely on-chain: smart contracts, deployed contract addresses, and technical documentation for integrating via web3 libraries and direct contract calls. There is no REST/HTTP API, hosted SDK, or OAuth surface; integration happens by calling the deployed contracts.'

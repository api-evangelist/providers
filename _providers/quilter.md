description: Quilter is a physics-driven AI platform that automates printed circuit board (PCB) placement and routing. Using reinforcement learning, it converts a schematic into multiple fabrication-ready layout candidates in hours instead of weeks, validating each against physical constraints through Physics Rule Checks (impedance control, differential pairs, power nets, bypass capacitors, keepouts, and stackup rules). Quilter supports Altium, Cadence Allegro, Siemens Xpedition, KiCAD, and OrCAD formats and handles boards of roughly 100-1,000 components with 2,000-5,000 pins to route. It is delivered as a hosted web application (app.quilter.ai) with a startup program and a free tier; there is no public developer API, SDK, or CLI surface at this time.

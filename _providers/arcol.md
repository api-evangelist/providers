description: Arcol is a browser-based, real-time collaborative building design and documentation platform for the architecture, engineering, and construction (AEC) industry, often described as a "Figma for BIM." Founded in 2021 by Paul O'Carroll and based in New York City, Arcol keeps massing, floorplans, metrics, estimating, and construction documentation connected in a single cloud-native workspace so early design decisions stay constructible. It supports multiplayer editing (built on Liveblocks), IFC and Excel import/export, a Rhino integration, and AI-assisted modeling. Arcol is backed by Cowboy Ventures and Craft Ventures. A public plugin API and developer SDK are described on the roadmap but are not yet published, so this profile currently exposes no programmatic API surface.

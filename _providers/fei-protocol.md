description: Fei Protocol was an Ethereum-based decentralized finance (DeFi) protocol that launched in April 2021, introducing FEI, an algorithmic stablecoin backed by Protocol Controlled Value (PCV), alongside the TRIBE governance token. Founded by Joey Santoro, it merged with Rari Capital in December 2021 to form the Tribe DAO. Following the April 2022 Rari Fuse exploit, the Tribe DAO voted to wind down and dissolve the protocol later that year. Fei Protocol was backed by a16z (Andreessen Horowitz), Framework Ventures, and other investors. Its smart-contract code and documentation remain public on GitHub, but the protocol is no longer operational and its web properties (fei.money, docs.fei.money) are offline. Fei Protocol is an on-chain smart-contract system and exposes no public REST/HTTP API, so it carries no OpenAPI, SDK, or hosted API artifacts.

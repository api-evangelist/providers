description: Versant Corporation was an American software company that built specialized object and NoSQL data-management systems, notably the Versant Object Database (VOD) and the FastObjects embeddable object database. Its persistence technology was accessed through language-native C++, Java (JDO/JPA-style) and .NET APIs rather than a REST web API, and was deployed across telecommunications, energy, financial services, transportation, manufacturing and defense. Backed by Trinity Ventures, Versant IPO'd on NASDAQ (VSNT) in July 1996 and was acquired by Actian Corporation in December 2012; the product line continues today as the Actian NoSQL Object Database.

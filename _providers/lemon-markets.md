description: lemon.markets is a Berlin-based, BaFin-licensed Brokerage-as-a-Service provider that sells white-label investment infrastructure as an API. Partners embed securities trading in their own products without holding a licence or operating custody, order routing, settlement, tax and reporting themselves. The Brokerage API covers account opening and KYC/ID+V, business and BPO accounts, securities accounts, instruments and prices across 10,000+ ETFs, stocks, bonds and funds, single and batch orders, trades, positions and financials, withdrawals and balance sweeps, corporate actions and income distributions, treasury mandates and transfers, German tax exemption orders (Freistellungsauftrag), documents, cash settlement, and recurring-investment workflows for savings plans. It is a REST API over JSON with bearer API-key auth, cursor pagination, an Idempotency-Key header on order creation, HMAC-signed webhooks across 83 event types, and a sandbox environment with published test ISINs.
  The API is invite-only.

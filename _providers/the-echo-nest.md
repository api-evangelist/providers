description: 'The Echo Nest was a music-intelligence company, spun out of the MIT Media Lab, that ran a developer platform and API for music understanding — machine-listening audio analysis (tempo, key, energy, danceability, valence), artist and song metadata, automated playlisting and taste profiles, and the Rosetta Stone service for translating artist and track IDs across music services. It was acquired by Spotify in March 2014 (reported at roughly €49.7M / ~$100M). Spotify consolidated onto its own Web API: The Echo Nest API stopped issuing new keys on 2016-03-29 and stopped serving requests on 2016-05-31, with developers directed to the Spotify Web API (whose audio-features and audio-analysis endpoints descend from Echo Nest technology). The developer.echonest.com portal no longer resolves; the echonest.com domain now redirects to an unrelated WordPress site. This profile was surfaced as a matrix-partners portfolio company; it is retained for historical/lineage reference and has no live,
  public API surface to enrich.'

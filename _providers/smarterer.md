description: Smarterer was a Boston-based skills-assessment company that used crowdsourced, adaptive tests to rapidly quantify people's proficiency across 400+ technical, social, and business skills. Backed by Google Ventures (GV), it opened a REST API in March 2015 that let partners embed tests, pull score data, and build leaderboards and profiles on top of its assessment engine. Pluralsight acquired Smarterer for roughly $75M in November 2014, absorbed its test engine into the Pluralsight learning platform, and wound down the standalone product. The smarterer.com domain no longer serves a site (defensively held via MarkMonitor, no DNS A record) and there is no live API surface to enrich.

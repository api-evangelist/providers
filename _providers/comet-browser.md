description: Comet is Perplexity's AI-native browser built on Chromium (Blink), integrating Perplexity Search and an agentic assistant that can summarize pages, draft emails, and complete tasks. Launched July 9, 2025 on Windows and macOS, with Android (Nov 2025), iOS (Mar 2026), and visionOS support added later. Initially gated behind a paid Perplexity subscription, opened free to everyone in October 2025. This is a consumer browser product with no publicly documented REST API surface.
features:
- Chromium-based (Blink engine) AI-native browser
- Perplexity Search as default with conversational answers
- Built-in AI assistant for page summarization
- Agent Mode for booking, shopping, drafting emails, multi-step tasks
- Windows 10+ and macOS Big Sur+ desktop apps
- Android 12+ mobile app (launched Nov 20, 2025)
- iOS 18+ mobile app (launched Mar 18, 2026)
- visionOS 2.0+ support
- Originally Perplexity Max/Pro subscriber exclusive
- Free to all users as of October 2025
- Proprietary licensing built on Chromium open-source foundation
- Researchers disclosed a "CometJacking" prompt-injection vulnerability in 2025

description: Bridgecrew was a developer-first cloud security company that pioneered infrastructure-as-code (IaC) security by creating Checkov, the open-source static analysis scanner for Terraform, CloudFormation, Kubernetes, Helm, ARM, Serverless, and Dockerfile configurations. Founded in 2019 and backed by Battery Ventures, Bridgecrew shipped a SaaS platform that scanned IaC and connected cloud accounts for misconfigurations, enforced policy guardrails in CI/CD, and remediated findings through automated pull requests. Palo Alto Networks acquired Bridgecrew in March 2021 for roughly $156 million and folded the platform into Prisma Cloud (now the PANW Application Security offering). The standalone Bridgecrew developer API and docs.bridgecrew.io documentation have since been retired, while Checkov remains actively maintained open source under the bridgecrewio GitHub organization and the www.checkov.io docs site.

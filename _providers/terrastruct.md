description: Terrastruct builds diagramming tools crafted to visualize software architecture. Its flagship product is D2, a modern, open-source (MPL-2.0) diagram scripting language that turns text into diagrams (SVG, PNG, PDF, PPTX, GIF, and ASCII). Terrastruct also builds D2 Studio, a hosted drag-and-drop and text-to-diagram IDE, and TALA, a proprietary layout engine designed specifically for software architecture diagrams. Rather than a public REST API, D2 is consumed as a CLI, as a Go library (d2lib / d2oracle) for programmatic diagram generation, and as a WASM-backed JavaScript library (D2.js), with official VSCode, Vim, and Obsidian editor plugins.

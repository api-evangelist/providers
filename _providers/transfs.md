description: TransFS (Transparent Financial Services, LLC) is the Chicago fintech that operated FeeFighters, a marketplace helping small and medium-sized businesses compare credit-card processors and reduce merchant-account fees. It also built the Samurai payment gateway, a developer-facing API for tokenizing cards and processing payments. FeeFighters was acquired by Groupon in March 2012 and folded into Groupon Payments / the Merchant Operating System, after which the Samurai gateway API was retired. The feefighters.com domain today operates as a credit-card fee-negotiation and chargeback-management consultancy under the FeeFighters name, promising fee reductions without switching processors; it publishes no public API, developer portal, or machine-readable API definition.

description: Unsloth is an open-source framework for fine-tuning, reinforcement learning, and running large language models locally. Its Python library trains 500+ models (text, vision, audio, embeddings) roughly 2x faster with up to 70-80% less VRAM via custom Triton kernels and dynamic quantization, and Unsloth Studio provides a local, browser-based GUI for no-code training and chat. Models loaded in Unsloth are exposed through an authenticated, OpenAI-compatible local API endpoint (llama-server) so agents like Claude Code, Codex, and standard OpenAI/Anthropic SDKs can use them; there is no hosted SaaS API.

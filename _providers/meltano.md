description: Meltano is an open-source, declarative, code-first data integration engine (ELT+) built on the open Singer standard. It lets data teams extract, load, transform, and test data across 600+ pre-built connectors sourced from Meltano Hub, managing entire pipelines as version-controlled code through the meltano CLI and a declarative meltano.yml project file. Meltano integrates with dbt for transformation and Elementary for data validation, and offers the Meltano Singer SDK for building custom taps and targets. It originated as a GitLab project and is backed by GV. Meltano exposes no public REST/HTTP API; it is a CLI-first DataOps platform.

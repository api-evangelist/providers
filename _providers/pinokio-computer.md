description: Pinokio is an open-source desktop application — self-described as an "AI Browser" — that acts as a 1-click launcher for any open-source AI project. Built by independent developer Cocktail Peanut (cocktailpeanut), Pinokio packages a terminal, package managers (Conda, Homebrew, Pip, NPM), and a graphical UI into a single MIT-licensed desktop app for macOS, Windows, and Linux with NVIDIA, AMD, and Apple Silicon GPU support. Users install AI apps with one click from a curated "Discover" directory of 160+ vetted scripts spanning image generation, video generation, text-to-speech and voice cloning, large language models, 3D generation, music and audio generation, and face swap. Pinokio is driven by a JSON-based scripting language designed to be both human and machine readable, with primitives like shell.run, fs, input, log, jump, hf (Hugging Face), notify, browser, and json that let publishers describe install and launch flows declaratively. Each script is sandboxed under ~/pinokio
  with isolated paths and Python virtual environments, and featured scripts must transfer ownership to the Pinokio Factory GitHub organization for admin review. Pinokio is purely client-side open source — there is no public REST API, no hosted commercial offering, and no developer SDK beyond the local script syntax and the desktop app itself.

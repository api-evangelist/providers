Wing unifies infrastructure and application code into a single model: a "preflight" phase compiles to Terraform/CloudFormation while an "inflight" phase compiles to JavaScript for runtime. Developers build and test distributed cloud systems locally with the Wing Simulator and Wing Console, then deploy to any major cloud provider. The project is MIT-licensed, ships the `wing` CLI (npm: winglang) and the standalone Wing SDK (@winglang/sdk, Apache-2.0), and the company is backed by Battery Ventures.

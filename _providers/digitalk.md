description: Digitalk, Inc. was an American object-oriented software tools vendor and a Trinity Ventures portfolio company, best known for Smalltalk/V — a commercial Smalltalk development environment first released in 1986 for MS-DOS, preceded by "Digitalk Methods" in 1983. It was founded by George Bosworth, Jim Anderson, Mike Teng and Barbara Noparstak, and its product line grew into Visual Smalltalk Enterprise. In July 1995 Digitalk merged with its principal competitor ParcPlace Systems; the combined company was later renamed ObjectShare, announced a shift away from Smalltalk toward Java in 1997, and active development of the Digitalk line ended shortly after. The final release, Visual Smalltalk Enterprise 2000, shipped in September 2000. Cincom retains the right to sell and support VSE 2000 for existing licensees and Seagull Software owns the virtual machine. Digitalk predates the public web API era and operates no developer platform, public API, or live web presence today; this profile

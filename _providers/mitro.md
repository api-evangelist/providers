description: Mitro was a password manager for individuals and teams, founded in 2012 in New York City by Vijay Pandurangan, Evan Jones, and Adam Hilss (former Google/Serious Eats engineers). It let multiple people securely share and control logins to a single account, architected around cloud storage with password databases encrypted client-side using keys derived from the user master password. Mitro raised $1.2M in seed funding from Google Ventures (GV) and Matrix Partners. On July 31, 2014 the team joined Twitter and released the Mitro source code on GitHub as free software under the GPL. The hosted Mitro service shut down on October 6, 2015; its open-source successor is Passopolis. The company is defunct and publishes no live API, developer portal, or reachable domain today.

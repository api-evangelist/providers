description: GEODNET (Global Earth Observation Decentralized Network) is a Web3/DePIN blockchain-based RTK (Real-Time Kinematics) GNSS correction network. It incentivizes operators to deploy permanent GNSS reference stations ("Satellite Miners") that broadcast real-time correction data, letting nearby devices achieve centimeter-level positioning accuracy. Station operators earn GEOD token rewards, with a target of 100,000 evenly distributed base stations worldwide — roughly twenty times larger than existing CORS networks. The correction data fuels robots, drones, autonomous vehicles, precision agriculture, construction, surveying, and consumer mapping. Developer-facing surfaces are the GEODNET Console web platform, the RTK coverage service, and DAO governance; the GEOD token spans Polygon and Solana. This profile was seeded as a Multicoin Capital portfolio lead and enriched by the API Evangelist pipeline.

description: Rookout is a live application debugging platform founded in 2017 in Tel Aviv, Israel that lets developers set non-breaking breakpoints in running production, staging, and development applications to capture full-stack debug data — variables, stack traces, logs, and metrics — without redeploying, restarting, or stopping services. Rookout pioneered the "live debugger" category for cloud-native and Kubernetes-hosted applications and shipped language agents/SDKs for Python, Java/JVM, Node.js, .NET, Go, and Ruby that attach to running processes and stream snapshots back to the Rookout web IDE or developer's IDE. Dynatrace announced its acquisition of Rookout on July 31, 2023 and closed the deal in Q2 of Dynatrace's fiscal year ending September 30, 2023. The standalone Rookout product has since been folded into the Dynatrace platform as the Dynatrace Live Debugger (and Live Logger), and the rookout.com and docs.rookout.com domains now redirect to dynatrace.com. There is no public
  REST API, OpenAPI specification, webhook catalog, or CLI for Rookout — the developer surface consists entirely of language agents, deployment integration examples, IDE extensions, and the Explorook desktop helper that exposes local source folders to the Rookout web debugger. The Rookout GitHub organization remains public and continues to maintain those agents, tutorials, and integration samples under Apache-2.0.

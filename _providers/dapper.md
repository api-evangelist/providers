description: 'Dapper was an advertising-technology and web-data company founded in 2006 by Jonathan Aizen and Eran Shir, seed-funded by Accel. It ran two surfaces: Dapper Ads, an intent-driven dynamic-ad product that pulled live product and inventory data from an advertiser''s own site into targeted creative without IT integration; and open.dapper.net (the "Dapp Factory" / Dapper: The Data Mapper), a hosted tool that turned any web page into structured feeds, web services and widgets — XML, RSS, JSON, YAML, CSV, iCalendar, Google Gadgets, Netvibes modules and image loops — effectively letting anyone "create an API for any site" before providers published their own. Dapper was acquired by Yahoo! in 2010 and both surfaces were shut down; dapper.net now resolves to Yahoo nameservers with no host, and open.dapper.net no longer resolves. There is no live API, developer portal, or documentation to enrich.'

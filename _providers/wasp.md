description: Wasp is an open-source, batteries-included full-stack web framework for the AI era. It uses a declarative configuration (the Wasp Spec, main.wasp.ts) layered on top of React, Node.js, and Prisma to generate a complete application, handling authentication, database and data models, background jobs, RPC, email sending, end-to-end type safety, and single-command deployment out of the box. Wasp also lets developers define custom HTTP API endpoints (powered by Express) and auto-generates CRUD operations. Created by Y Combinator- and HV Capital-backed twin founders Matija and Martin Sosic, Wasp aims to let teams ship production-ready apps in a day while remaining friendly to both human and AI-assisted coding workflows.

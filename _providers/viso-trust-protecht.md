description: VISO TRUST is an AI-powered third-party risk management (TPRM) platform that automates vendor security due diligence — document analysis via Artifact Intelligence, inherent/residual risk scoring, questionnaire automation, vendor discovery, and continuous monitoring with risk advisories. Its public Client API (bearer-token authenticated, served from https://app.visotrust.com/api/v1) lets security programs create and manage vendor relationships, start and retrieve assessments, export assessment summaries, pull vendor risk summaries and external intelligence reports (BitSight, Recorded Future, SecurityScorecard), query the vendor directory, manage users, read audit logs, and register outbound webhooks across a 15-event catalog. A hosted MCP server (mcp.visotrust.com) exposes the same surface to AI agents using the same token.

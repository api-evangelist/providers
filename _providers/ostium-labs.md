Built on Arbitrum, the protocol pairs an on-chain OLP vault with an off-chain hedge that settle daily across three core participants. For developers, Ostium ships an official TypeScript Builder SDK (@ostium/builder-sdk) and a Python SDK (ostium-python-sdk) plus a public Builder API for live prices, OHLC candles and WebSocket price/account streaming, backed by a GraphQL subgraph.

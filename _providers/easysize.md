description: EasySize is an AI-powered size-recommendation platform for fashion e-commerce, marketed as "Fit Quiz." It helps clothing, footwear, sportswear, and swimwear retailers reduce returns and increase conversion by giving shoppers a personalized size recommendation without asking them for body measurements. EasySize ships as a native Shopify app and as a JavaScript library ("web app") that merchants embed on non-Shopify storefronts; the library is configured with a merchant-specific shop_id and product context and renders an in-page Fit Quiz widget. Merchants wire order-tracking and return-tracking events back to EasySize so the recommendation algorithm can learn, and can capture emails and drive personalized flows through a Klaviyo integration. EasySize supports 11+ languages with auto-detection, multiple size formats (UK/EU/US/international/custom), unisex and gender-aware logic, and additional fit/width/length recommendations. The company was a portfolio company of 500 Global.

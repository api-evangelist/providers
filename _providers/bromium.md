description: Bromium was an endpoint-security company founded in 2010 that pioneered application isolation through hardware-enforced micro-virtualization, running each untrusted task (a web page, email attachment, or downloaded file) inside its own disposable CPU-level micro-VM so malware could not escape to the host. Bromium was surfaced as a portfolio company of a16z and Lightspeed Venture Partners. Hewlett-Packard (HP Inc.) acquired Bromium in September 2019 and folded the micro-virtualization technology into HP Sure Click and the HP Wolf Security endpoint-protection line; bromium.com now permanently redirects to HP's endpoint-security pages. Bromium no longer operates as an independent entity and publishes no standalone public developer API, so this profile carries company identity only rather than API artifacts.

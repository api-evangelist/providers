description: MISMO — the Mortgage Industry Standards Maintenance Organization — is the standards development body for US real estate finance, founded in 1999 and a not-for-profit wholly owned subsidiary of the Mortgage Bankers Association since 2004. Its Reference Model defines the data of a loan from application through closing, servicing and the secondary market, and version 3.6 ships an XML schema, a Logical Data Dictionary, a Unique ID Matrix and a YAML file set that conforms to the OpenAPI Specification, alongside a MISMO API Toolkit and services such as a FIPS Code API. Around the Reference Model sit sixteen dataset specifications — iLAD, the Mortgage Compliance Dataset, the IRS 4506-C, the VA forms, adverse action, closing instructions — plus SMART Doc and the eMortgage and eNote work, and certification programmes for RON, eClosing, eVault and SMART Doc systems. MISMO standards are accepted and deployed by every type of entity involved in creating mortgages and are required by most
  regulators, housing agencies and the GSEs. It governs in the open — fourteen bodies and their rosters are published — and distributes behind a $3,500 annual membership and a licence agreement, which is the exact inverse of the specifications-as-code posture CAMARA and NMFTA took.

description: LedgiFi (formerly Krypto Ledgers) is a Latin American cryptocurrency tax and portfolio-tracking platform founded in 2020 and headquartered in Antofagasta, Chile. The product syncs a user's transaction history from exchanges and wallets — Binance, Coinbase, Kraken and MetaMask among them — normalizes it across more than 25,000 assets, and computes realized capital gains using the valuation methods and monetary-correction adjustments each jurisdiction requires, so investors can file a compliant return. Its Chilean profile applies the SII's specific rules (IPC indexation and dollar-variation adjustments, Impuesto de Primera Categoría and Impuesto Global Complementario), and the platform has since expanded to Mexico, Spain, Colombia and Argentina. Alongside tax reporting it offers a portfolio view spanning crypto, stocks and ETFs, with per-asset performance and allocation. LedgiFi is a 500 Global (500 LatAm B18) portfolio company. It runs a monitored production API at api.ledgifi.com
  that backs its own web and mobile apps, but publishes no developer portal, no API specification and no self-service API program.

description: 'Placenote (Vertical AI Inc.) was a San Francisco company that built a cloud-hosted persistent augmented-reality toolkit — a "Persistent AR" SDK that let developers save, reload, and share ARKit/Unity spatial maps so digital content stays anchored to a physical location across sessions and devices. It shipped native client SDKs for iOS (Swift, via the PlacenoteSDK CocoaPod) and Unity, plus multiplayer AR samples such as PlaceInvaders and web mesh-viewing examples. The product was consumed as mobile SDKs backed by a cloud mapping/localization service rather than a public REST API, so no OpenAPI or web API surface was published. The company is now defunct: placenote.com no longer resolves to a live product (the domain is parked) and the docs/cloud service are offline. The Placenote GitHub organization and the published SDKs remain the only live, first-party developer surface, which is what this profile captures.'

description: LaunchKit was a set of web-based tools for mobile app developers, built by Cluster Labs, Inc. in San Francisco and backed by GV. Its products included Screenshot Builder for App Store screenshots, Review Monitor for App Store review alerts, a Sales Reporter, hosted App Websites, and Super Users and Cloud Config delivered through the LaunchKit iOS SDK. LaunchKit joined Google in 2016 and the codebase was released as open source under Apache 2.0. There is no live hosted LaunchKit API, developer portal, or documentation today; the surviving surface is a self-hostable Django/JavaScript codebase on GitHub plus an unmaintained Objective-C SDK on CocoaPods. The original launchkit.io domain is no longer company-controlled and now serves an unrelated content site.

description: Kota is a Dublin-headquartered employee benefits platform that gives payroll, HR and employer-of-record platforms embedded access to health insurance, workplace pensions, life assurance, flexible benefits and spend cards across Ireland, the UK, Spain and other markets. Kota Embedded is sold as three developer products — a Hosted redirect experience, an Embed JavaScript SDK (Kota.js) that drops themed employer and employee benefit UIs into a partner platform, and a full REST API for building a completely custom benefits journey. The Kota API is an OpenAPI 3.1 contract at api.kota.io covering employers, employees, groups, group policies, policies, plans, health insurance quotes and offers, contribution reports, associated persons/dependents, and a family of intent resources (group quote, group policy, enrolment, dependents management, policy amendment, policy import) that model each step of the benefits lifecycle. Authentication is API key bearer tokens with pk_test_/pk_live_
  prefixes, POST requests accept an Idempotency-Key header, errors conform to RFC 9457 Problem Details, and a large webhook catalog (v1 and v2 event families) publishes employer, employee, group, policy, quote and contribution-report state changes.

description: DBND (Databand) is an open-source Python framework — a library, a set of APIs, and a CLI — for building, tracking, and observing data pipelines across data ingestion, preparation, ETL/ELT, and machine-learning workflows. It collects pipeline metadata (runs, metrics, dataframes, schemas) to give data-engineering teams a system of record for runs and to detect pipeline failures and data quality issues before they hit downstream consumers. The DBND SDK integrates with Apache Airflow, Apache Spark, Databricks, dbt, and IBM DataStage. Databand was acquired by IBM in 2022 and is now IBM Databand, part of IBM's data observability offering; the open-source DBND SDK remains published on PyPI and GitHub under the databand-ai organization.

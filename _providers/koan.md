description: 'Koan was a goal-management SaaS at koan.co that billed itself as "The Free OKR and Status Tracking Platform", pairing OKR goal setting with a weekly "Reflections" status-update loop and an Insights layer so teams tracked progress as a habit rather than a quarterly spreadsheet exercise. The product shipped a Goal Metrics API — enabled per goal via an API integration toggle on the goal edit page — so teams could push their most important numbers into Koan goals in real time, alongside a Zapier app and native integrations with Slack, Jira, and Okta SSO. Koan was acquired by Gtmhub, an acquisition announced on its own homepage and blog by January 2022, and surfaced in the API Evangelist network as an Uncork Capital portfolio company. As of enrichment the koan.co domain no longer serves the product: it redirects to a GoDaddy domain-for-sale lander, and there is no live developer portal, documentation, API reference, SDK, or status surface left to harvest.'

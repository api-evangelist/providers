description: 'Element (Element Finance) is an Andreessen Horowitz-backed decentralized finance protocol for fixed and variable yield on crypto assets. The protocol splits an interest-bearing position into tradable Principal Tokens (PTs) and Yield Tokens (YTs) so users can lock in a fixed rate by buying discounted principal, or take variable-rate exposure, redeeming at face value on maturity via on-chain AMMs. It also ships the Council governance framework (voting vaults, delegation, the Governance Steering Council) that powers the Element DAO. Element is a smart-contract protocol on Ethereum rather than a hosted REST API: developers integrate through the on-chain contracts, the elf-sdk TypeScript library, and the published contract reference. The team has since rebranded to DELV (delvtech).'

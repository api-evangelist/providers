Its Data Management API ingests users, locations, meters, consumption readings and tariff price formulas — synchronously or as asynchronous NDJSON bulk jobs — and its Insights API returns presentation-ready analytics on top of that data: consumption and cost by day, week, month and year, CO2 footprint, appliance-level disaggregation (NILM), day-ahead market prices, peak power and dynamic capacity, tariff comparison, PV production, forecasting, anomaly detection, similar-homes benchmarking, budgets and personalised advice. An Intelligence API adds portfolio segmentation for utility service and growth teams, and an OAuth 2.0 Auth API issues app and delegated tokens for all of it. Eliq also ships 20 embeddable web components and pushes notification webhooks signed with HMAC-SHA256. Access is commercial — credentials are issued by an

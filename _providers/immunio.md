description: IMMUNIO was a Montreal-based application security company (founded 2013) that built a real-time RASP (Runtime Application Self-Protection) platform to detect and block attacks against web applications and APIs without requiring code changes. Its product shipped as language-native agents for Ruby on Rails, Python (Django/Pyramid/Flask), Node.js/Express, Java, PHP, Scala and .NET, covering the OWASP Top 10 including Cross-Site Scripting and SQL Injection. The company raised roughly $8M from Bloomberg Beta, WhiteStar Capital, Real Ventures, Hoxton Ventures and BDC, and was acquired by Trend Micro in November 2017, where the technology was folded into Trend Micro's hybrid cloud and container security for the DevOps lifecycle. The immun.io and docs.immun.io properties have since been retired; the durable public surface today is the first-party agent libraries on RubyGems, PyPI and npm and the IMMUNIO GitHub organization.

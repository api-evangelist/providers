description: Alooma was a cloud data-pipeline (ETL) platform founded in 2013 in Palo Alto and Tel Aviv that let enterprises stream and migrate data from sources such as SQL Server, Oracle, Amazon Aurora, Salesforce, Zendesk, and Zuora into data warehouses including Google BigQuery, Amazon Redshift, and Snowflake. It offered a hosted pipeline with a REST API input connector and a first-party Python client (alooma.py) for programmatic management of inputs, mappings, and tables. Google Cloud acquired Alooma in February 2019 and wound the standalone product down; the alooma.com developer surface no longer resolves. This profile is retained as a historical/acquired-company record surfaced from the Lightspeed Venture Partners portfolio.

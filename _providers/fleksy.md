description: Fleksy (Thingthing Ltd) was a keyboard technology company that built a mobile Keyboard SDK — a white-label, privacy-focused typing engine that iOS and Android developers could embed in their own apps. The SDK provided autocorrect, next-word prediction, swipe/gesture typing, customizable themes, and a plugin system, and the Fleksy keyboard once held Guinness World Records for the fastest typing. Fleksy distributed a native mobile SDK rather than a public web/REST API, so it exposes no OpenAPI, GraphQL, or hosted developer portal. Backed by Seedcamp and Speedinvest, the company's public web presence (fleksy.com, docs.fleksy.com, fleksy.dev) no longer resolves and the business appears defunct; this profile captures the surviving public artifact — the first-party FleksySDK CocoaPods pod for iOS.

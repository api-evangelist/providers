description: ironSource is a Tel Aviv-based mobile game growth platform, acquired by Unity Technologies in a $4.4B all-stock deal that closed in November 2022 and is now operated as part of Unity's Grow Solutions group. The company builds an end-to-end suite for mobile game developers spanning ad monetization, user acquisition, and ad operations. Its flagship product LevelPlay is a unified in-app bidding and ad mediation platform that brokers Rewarded Video, Interstitial, and Banner ad demand across the ironSource Ads network, AdMob, AppLovin, Meta Audience Network, Pangle, Mintegral, Unity Ads, Vungle, and dozens of other ad sources. ironSource Ads is its self-serve ad network and user-acquisition platform offering CPI, CPE, ROAS-optimized, and SKAdNetwork-aware campaign management. Adjacent products include Aura (an on-device content marketplace for carriers and OEMs that originated from the 2021 Bigabid/Soomla portfolio and earlier hardware OEM deals), Tapjoy Offerwall (acquired 2022)
  for rewarded engagement, and Ad Quality for ad-content monitoring. Developer access is via a REST surface hosted at platform.ironsrc.com — including the Monetization Reporting API (v5/v4), ironSource Ads Reporting API, Application API (v6), Campaign API suite (Campaigns, Audiences, Country Groups, Bidding, Assets, Creatives), SKAN Reporting API, and Cost API — authenticated with Bearer tokens issued from the platform dashboard. Real client integration is delivered via native SDKs (iOS, Android, Unity, Flutter, React Native, Adobe AIR, Xamarin) plus the LevelPlay mediation adapter ecosystem published on github.com/ironsource-mobile. As of 2026 the developers.is.com knowledge center 301-redirects to docs.unity.com, consolidating ironSource documentation inside Unity Grow alongside Unity Ads. No public OpenAPI, Postman collection, or JSON Schema bundle is published by ironSource for the REST surface; documentation is human-readable HTML on docs.unity.com/en-us/grow.

description: API-Sports is a sports-data provider selling twelve independent read-only REST APIs — one per sport — covering football, basketball, baseball, American football (NFL and NCAA), NBA, Formula 1, ice hockey, handball, rugby, volleyball, MMA and Australian rules football. Each API returns live scores, fixtures and schedules, standings, team and player statistics, lineups, injuries, transfers, odds and multi-season historical results, and each is versioned independently with its major version carried in the hostname. A single API key works across every sport an account subscribes to, authenticated with an x-apisports-key header, and the same APIs are resold through the RapidAPI marketplace. API-Sports also ships a first-party embeddable widget library that renders games and standings with no client code.

description: Kalderos is a Chicago-based healthcare technology company, founded in 2016, that built what it calls the first Drug Discount Management platform. It helps pharmaceutical manufacturers, covered entities (safety-net healthcare providers), and state Medicaid programs manage compliance across U.S. drug discount programs — most notably 340B — using data, AI, and machine learning to identify noncompliant or duplicate discounts, streamline good-faith-inquiry and dispute resolution, and move rebates transparently between stakeholders. Marquee products include 340B Pay, the Truzo rebate-payment platform, Discount Hub for covered entities, and MDRP and Commercial Discount Monitoring for manufacturers. Kalderos was acquired by Model N in 2024 to expand Model N's revenue-management and 340B capabilities for life sciences. This profile was surfaced as a portfolio company of Bain Capital Ventures and enriched by the API Evangelist pipeline; Kalderos operates a customer-facing application
  (app.kalderos.com) and previously published developer API documentation that is no longer resolvable post-acquisition.

description: Sunscreen is a cryptography company building the Secure Processing Framework (SPF) — an end-to-end platform for Fully Homomorphic Encryption (FHE) on blockchain. SPF lets web2 and web3 developers write programs, compile them to the Parasol FHE processor, and run them over encrypted data on-chain without ever exposing plaintext. The stack includes the open-source Sunscreen FHE/ZKP compiler (a family of Rust crates on crates.io), the Parasol processor runtime, a TypeScript SDK (@sunscreen/spf-client) and a Rust CLI for encrypting values, uploading FHE programs and ciphertexts, requesting threshold decryption, and managing on-chain access control (ACL). Founded by cryptographers and engineers from Nucypher, Microsoft, Meta, Tableau, Two Sigma and Caldera, and backed by Northzone.

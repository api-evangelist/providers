description: Agoric is a Cosmos-based Layer 1 blockchain that lets developers build secure cross-chain smart contracts in Hardened JavaScript (SES). Its Orchestration API abstracts multiple chains so a single long-lived contract can manage assets, accounts, and services across the multi-chain universe. The platform is built around Zoe (a smart-contract framework that enforces offer safety), ERTP (the Electronic Rights Transfer Protocol for issuing and transferring digital assets), and SwingSet (its deterministic async VM). Developers ship dapps with the `agoric` CLI and `agd` Cosmos daemon, query chain state through vstorage, and integrate with the network over Cosmos RPC and IBC. The developer surface is delivered as first-party `@agoric/*` npm packages rather than a REST API. Originally surfaced as a Polychain portfolio company, this profile has been enriched from Agoric's public developer platform.

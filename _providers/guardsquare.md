description: Guardsquare is a mobile application security company that protects iOS and Android apps against reverse engineering, tampering, and runtime attacks through a multilayered defense platform. Its products include DexGuard (Android code hardening, polymorphic obfuscation, and RASP), iXGuard (the iOS equivalent for native and cross-platform apps and SDKs), AppSweep (mobile application security testing that finds vulnerabilities in app code and dependencies and integrates into CI/CD), ThreatCast (real-time post-release threat monitoring), and App Attestation (server-side runtime verification that only genuine apps can reach your APIs). Guardsquare also maintains the widely used open-source ProGuard family of Java bytecode shrinking, optimization, and obfuscation tooling. Protections cover Java, Kotlin, Swift, Objective-C, and cross-platform frameworks including React Native, Flutter, Unity, Cordova, and Ionic.

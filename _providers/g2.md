The G2 API provides programmatic access to G2's product catalog, category taxonomy, vendor records, reviews, badges, Grid reports, buyer intent signals and competitive intelligence. The v2 REST surface is a JSON:API contract of 62 operations served from data.g2.com, alongside a separate Data Solutions API for enriched flat-structure review data and a first-party remote MCP server at mcp.g2.com that exposes 21 tools to AI agents over OAuth 2.0. Authentication is by Developer Portal account token or OAuth 2.0 authorization code with PKCE, and most data surfaces are gated by subscription entitlement.

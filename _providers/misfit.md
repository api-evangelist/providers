description: Misfit is a consumer wearables brand — fitness trackers and smartwatches such as the Misfit Shine, Flash, Ray and Vapor — founded in 2011 by Sonny Vu, John Sculley and Sridhar Iyengar and backed by Norwest Venture Partners, Khosla Ventures, Founders Fund, GGV Capital and Xiaomi before being acquired by Fossil Group in 2015. Misfit ran a developer program (the Misfit Cloud API, Device SDK and Scientific Library) at build.misfit.com with 30+ launch partners. Fossil discontinued the Misfit backend, Cloud API and companion app in spring 2023, so the hosted API and all misfit.com domains are now unreachable. The only surviving developer surface is the official Misfit-Developers GitHub organization and its unmaintained iOS SDKs on CocoaPods.

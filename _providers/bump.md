description: Bump Technologies was a Mountain View, California mobile software company (2008-2014) behind Bump, an iOS and Android app that let two people exchange contacts, photos and files by physically bumping their phones together. Bump servers correlated accelerometer, location and network signals from two handsets to match the pair, then brokered the transfer. The company published a first-party Bump API and iOS/Android SDKs so third-party apps could embed the same proximity-matching handshake. Backed by Y Combinator, Sequoia Capital and a $16M Series B led by Andreessen Horowitz in January 2011, Bump was acquired by Google in September 2013 and both the app and its developer API were discontinued on January 31, 2014. The company's bu.mp domain still serves its shutdown notice and the archived SDK repositories remain public under the bumptech GitHub organization; there is no live API surface.

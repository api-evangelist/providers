Its APIs let businesses connect to customers' bank accounts to read financial data (accounts, balances, transactions, identity, income and credit insights) and to move money via pay-by-bank payments, Account-on-File consents, payment links, payouts, refunds and scheduled payments. Lean provides the LinkSDK client for web, iOS, Android, React Native and Flutter, a FAPI-grade OAuth 2.0 authorization server, webhooks, a hosted documentation MCP server, and public Postman collections.

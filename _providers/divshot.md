description: Divshot was a front-end and static web application hosting platform based in Santa Monica, California, and a 500 Global portfolio company. It offered command-line deploys of single-page and static applications across development, staging and production environments, with instant environment URLs, custom domains and SSL certificate upload, environment variables and app configuration, HTTP basic-auth protection of environments, cache purging, release promotion and rollback, and per-app webhooks. Divshot published a first-party CLI (divshot-cli) and a JavaScript API client (divshot-api) on npm, and open-sourced Superstatic, the static web server behind the platform. Divshot was acquired by Google in 2015 and folded into Firebase Hosting. The service is defunct - divshot.com no longer resolves and no live API, documentation or developer portal remains. This profile is a historical record built from the surviving first-party npm packages and GitHub repositories.

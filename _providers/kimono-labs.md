description: Kimono Labs was a developer-tools startup that let users turn any website into a structured API without writing code, using a visual point-and-click tool to define data selectors that Kimono would crawl on a schedule and expose as JSON/CSV endpoints and RSS feeds. Founded in 2014 by Pratap Ranade and Ryan Rowe and backed by Cowboy Ventures, the company was acquired by Palantir Technologies in February 2016, after which the hosted cloud service at kimonolabs.com was shut down on 29 February 2016; a downloadable Kimono Desktop application was released as a farewell so existing scrapers could continue running locally. The company is defunct and operates no live API today; this profile is retained for historical and network completeness.

description: LightCyber was an Israeli-American cybersecurity company that pioneered a category it called Behavioral Attack Detection — using behavior-based profiling of network traffic and endpoint activity, rather than malware signatures or technical artifacts, to detect attackers already operating inside an enterprise network. Its LightCyber Magna platform shipped as a set of appliances and services (Magna Detector, Magna Probe, Magna Master, Magna Pathfinder, and the Magna Cloud Expert System) and was positioned for user and entity behavior analytics (UEBA), network traffic analysis, security visibility, and PCI compliance. The company was backed by Battery Ventures, Glilot Capital Partners, Amplify Partners, and angel investor Shlomo Kramer. Palo Alto Networks announced the completed acquisition of LightCyber for $105 million in cash on February 28, 2017, and engineered its automated behavioral analytics into the Palo Alto Networks security platform. The independent LightCyber brand,
  product line, and web presence no longer exist; the lightcyber.com domain has since lapsed from Palo Alto Networks' control and now resolves to an unrelated third-party site. This profile is retained in the API Evangelist network as an acquired-company lead and carries no live API artifacts.

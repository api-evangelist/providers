description: 'Datos IO was a Silicon Valley data-management startup, backed by Lightspeed Venture Partners, that built RecoverX — an "application-centric" backup, recovery and data-mobility platform for cloud-native and distributed databases. RecoverX targeted NoSQL and cloud data stores including Apache Cassandra, DataStax, MongoDB, Couchbase and Amazon DynamoDB, alongside relational sources such as Microsoft SQL Server, and used parallel data streaming, semantic deduplication and a distributed metadata catalog to back up in native formats and recover across private, hybrid and public cloud. Datos IO was acquired by Rubrik in 2018 and operated for a period as "Rubrik Datos IO" before the brand was retired. The company has no independent presence today: the datos.io domain has lapsed and is listed for sale through a domain broker, and no live developer portal, documentation or API surface remains.

description: 'Datos IO was a Silicon Valley data-management startup, backed by Lightspeed Venture Partners, that built RecoverX — an "application-centric" backup, recovery and data-mobility platform for cloud-native and distributed databases. RecoverX targeted NoSQL and cloud data stores including Apache Cassandra, DataStax, MongoDB, Couchbase and Amazon DynamoDB, alongside relational sources such as Microsoft SQL Server, and used parallel data streaming, semantic deduplication and a distributed metadata catalog to back up in native formats and recover across private, hybrid and public cloud.

description: 'Ximian was a Boston-based open source software company founded on October 19, 1999 by Miguel de Icaza and Nat Friedman -- originally incorporated as International GNOME Support, then Helix Code, and renamed Ximian in January 2001. It advanced the GNOME desktop, built the Evolution email and collaboration client and Ximian Connector, ran the Red Carpet software-update service, and launched the Mono open source .NET implementation. Surfaced via the Battery Ventures portfolio, Ximian was acquired by Novell on August 4, 2003 to strengthen Novell''s enterprise Linux business; after Attachmate acquired Novell in 2011 the founders went on to create Xamarin (acquired by Microsoft in 2016). Ximian no longer operates: www.ximian.com still resolves on Novell infrastructure but permanently redirects every path to novell.com/linux/ximian.html, which forwards to suse.com -- there is no live website, developer portal, or public API surface.

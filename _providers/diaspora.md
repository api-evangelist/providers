description: diaspora* is a privacy-aware, decentralized, open source social network, launched in 2010 and released under the AGPL. Rather than running on servers owned by a single company, diaspora* runs as a federated network of independently operated servers called "pods" — anyone can join an existing pod or host their own, and users own their own data. Its "aspects" model lets people organize contacts into groups and control exactly which audience sees each post, alongside hashtags, mentions, reshares, likes, polls, photos and private conversations. Pods federate with each other using the diaspora* federation protocol. Since release 0.9.0.0 the project officially supports third-party applications through a documented JSON REST API at /api/v1 on every pod, authenticated with OpenID Connect Core 1.0 including Dynamic Client Registration — a necessity in a decentralized network where an application cannot pre-register with every pod it might talk to.

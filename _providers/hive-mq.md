description: HiveMQ is the real-time industrial data platform built on MQTT, developed by HiveMQ GmbH (Berlin, Germany). It provides an enterprise-grade MQTT message broker for reliable, scalable, and secure bidirectional data movement between IoT and OT devices and enterprise IT systems. The HiveMQ platform spans the self-managed HiveMQ Broker, the fully managed HiveMQ Cloud service, HiveMQ Edge (a software edge gateway that bridges OT protocols such as OPC-UA and Modbus to MQTT), HiveMQ Data Hub (in-broker data policy, validation, and transformation), HiveMQ Pulse (distributed data intelligence), and an extensible Extensions SDK for IT integrations (Kafka, security, monitoring). HiveMQ fully supports MQTT 3.1.1 and MQTT 5.0 as well as MQTT Sparkplug for unified namespace architectures, and offers open-source client tooling including the Java hivemq-mqtt-client library and the MQTT CLI. It is used in production for connected cars, manufacturing, logistics, and energy by companies including
  BMW, Mercedes-Benz, Ford, Air France-KLM, and Unilever.

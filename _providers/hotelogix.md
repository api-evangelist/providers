description: Hotelogix is a cloud-based hotel property management system (PMS) headquartered in Noida, India, serving more than 12,000 independent hotels, groups, chains, and resorts across 100+ countries since 2008. The platform provides front desk management, reservations, point-of-sale, housekeeping, revenue management, multi-property and group management, a web booking engine, a guest service mobile app, and an integrated channel manager that distributes inventory to OTAs and GDS. Hotelogix exposes a partner Web API (HAPI) at developer.hotelogix.net that uses XML POST over HTTP rather than REST/JSON, enabling channel managers, payment gateways, accounting systems, CRMs, loyalty programs, door locks, ID scanners, and in-room devices to integrate with the PMS. Documentation is split into Web (booking engine), Admin, and Frontdesk surfaces. There is no public OpenAPI specification, no public SDK, and no public GitHub org content; partner access and credentials are granted on request through
  the Hotelogix support and partnership teams. Revenue model is SaaS subscriptions per hotel/room along with an integration marketplace ecosystem.

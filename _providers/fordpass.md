The Ford Developer Marketplace (developer.ford.com) hosts Ford's partner-facing API program — FordConnect Query API for consumer-vehicle data and remote command access (with vehicle-owner consent via FordPass account OAuth), plus a Ford Pro REST API surface for fleets including Vehicle Status, Vehicle Historical Status, Vehicle Metadata, Vehicle Efficiency (fuel/energy/idle),

Ford Pro Telematics is integrated with Geotab, Fleetio, Samsara, Motive, Verizon Connect, and other fleet platforms, and Smartcar offers a consumer OAuth bridge to Ford vehicles using FordPass Connect credentials. Access to Ford APIs is gated behind a partner application and credentials issued through the Ford Developer Portal; Ford has periodically restricted individual-developer access.

description: Skuid is a low-code application-development platform for building custom, data-connected user experiences on top of Salesforce and other enterprise systems. Builders assemble Pages from configurable UI components bound to Models, which read and write data through Data Sources (Salesforce, REST, OData, SQL, Google, OpenAI, and more). Rather than a hosted REST API, Skuid exposes a client-side JavaScript API (skuid.model, skuid.$, snippets, and component-specific APIs) plus a data-source Merge API, and ships first-party developer tooling — a Go deployment CLI (skuid-cli) and a Salesforce DX plugin (skuid-sfdx) for moving metadata between environments. Skuid was acquired by Nintex and is now delivered as Nintex Apps. Originally surfaced as a portfolio company of ICONIQ Capital and enriched by the API Evangelist pipeline.

description: CipherCloud was a cloud security company, founded in 2010, that pioneered the cloud access security broker (CASB) category. Its platform provided encryption and tokenization, data loss prevention, cloud discovery and shadow IT visibility, threat protection, and compliance controls for SaaS applications such as Salesforce, Office 365, ServiceNow, and Box. Backed by Andreessen Horowitz (a16z) and Index Ventures among others, CipherCloud was acquired by mobile and cloud security vendor Lookout in early 2021, and its CASB technology was folded into Lookout's Secure Cloud Access offering. The standalone ciphercloud.com developer and product surface has since been retired; this profile is retained in the API Evangelist network as a historical company record.

description: Compose (Compose, Inc., compose.io) was a database-as-a-service (DBaaS) provider that offered production-ready, auto-scaling, hosted deployments of open-source databases — MongoDB, PostgreSQL, Redis, Elasticsearch, RabbitMQ, RethinkDB, ScyllaDB, etcd, MySQL, and Disque — each provisioned with high availability, automated backups, and a REST API for programmatic management. Founded in 2010 as MongoHQ and rebranded to Compose in 2014, the company was backed by DCVC (Data Collective) and was acquired by IBM in 2015, after which the offering was folded into IBM Cloud as "IBM Compose" / IBM Cloud Databases. The standalone Compose service and its developer surface (compose.com, compose.io, apidocs.compose.com) have since been deprecated and taken offline. This profile documents the surviving, verifiable first-party artifacts — the archived GitHub organization at github.com/compose, the official Go SDK (gocomposeapi) wrapping the Compose REST API, and the official command-line tools
  (bach, cocli).

description: Cape is a privacy-first U.S. mobile carrier (mobile virtual network operator) that leases physical tower capacity from major operators but builds and runs its own mobile core and SIMs, enabling privacy-enhancing controls that traditional carriers cannot offer. Features include daily identifier rotation (changing SIM ID numbers to disrupt persistent tracking), minimal data collection, disappearing call logs, secondary phone numbers, SIM-swap protection, network lock, and secure global roaming. Founded in 2022 by John Doyle and Nicholas Espinoza and headquartered in Arlington, Cape serves privacy-conscious consumers, enterprises, and U.S. government agencies, and has raised roughly $190M from investors including Andreessen Horowitz, Bain Capital Ventures, IVP, and Costanoa Ventures. Cape publishes no public developer API; this profile is an API Evangelist network company record enriched from Cape's public web surface.

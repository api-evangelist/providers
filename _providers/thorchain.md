description: 'THORChain is a permissionless, decentralized cross-chain liquidity protocol (a Cosmos-SDK / CometBFT Layer-1) that enables native asset swaps between independent blockchains — such as Bitcoin, Ethereum, and Cosmos assets — without wrapping, bridging, or centralized custody. Liquidity providers earn fees on continuous liquidity pools denominated against the RUNE settlement asset, and swaps are secured by a rotating set of bonded THORNode validators using threshold-signature (TSS) vaults. For developers, THORChain exposes two open, read-only, unauthenticated HTTPS APIs: the THORNode application REST API (pools, swap quotes with ready-to-use memos and inbound vault addresses, transactions, nodes, vaults, THORNames, savers, trade accounts, RUNEPool and network state) and the Midgard indexer API (time-series history, actions, analytics, and member details). It also publishes an agent-native discovery surface — an MCP server card, AGENTS.md, ai-plugin manifest, and llms.txt.'

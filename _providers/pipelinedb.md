description: PipelineDB was a high-performance PostgreSQL extension for continuous, incremental aggregation of time-series data using continuous SQL views, avoiding the need to store raw event data. It also offered Stride, a hosted streaming-analytics API with first-party Python, JavaScript, and Go client SDKs, plus extensions for Apache Kafka and Amazon Kinesis ingestion. The company joined Confluent in 2019; the open-source extension reached a final 1.0.0 release (Apache-2.0) and is now archived, while the pipelinedb.com website and the hosted Stride service have been retired. Added to the API Evangelist network as a portfolio company of DCVC.

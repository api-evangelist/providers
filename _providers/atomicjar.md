description: AtomicJar is a developer-testing company, founded in 2021 by the original creators and maintainers of the open-source Testcontainers project and acquired by Docker in December 2023. AtomicJar builds tooling that lets developers run reliable integration tests against real service dependencies (databases, message brokers, and other systems) defined in code and wrapped in Docker containers, replacing brittle mocks and in-memory fakes. Its product line spans Testcontainers OSS (the open-source libraries for Java, .NET, Go, Node.js, Python, Rust, and more), Testcontainers Desktop (a companion app for local development), and Testcontainers Cloud (a hosted service that offloads container execution to the cloud so tests run consistently from a laptop through CI without a local Docker daemon). AtomicJar and its Testcontainers products are used by engineering teams at companies including Spotify, Uber, Capital One, Elastic, Netflix, and Zalando.

description: 'Argon Networks was a late-1990s networking infrastructure startup that developed a high-speed routing switch for what was then described as the next-generation multi-service Internet, combining IP routing with ATM switching in a single carrier-class platform. The company was venture backed by Canaan Partners (Series B, partner Eric Young), Matrix Partners, New Enterprise Associates and Greylock. Siemens acquired Argon Networks in March 1999 in a deal reported at roughly $240 million and folded the team into Unisphere Solutions / Unisphere Networks, the carrier-infrastructure unit later acquired by Juniper Networks in 2002. Argon Networks predates the public web API era: it shipped carrier networking hardware, never operated a developer program, and has no surviving website, documentation, SDKs or API surface.
